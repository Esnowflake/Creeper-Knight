# 苦力怕骑士 3.0 · Minecraft Java 1.20.1

加入玩家驾驶苦力怕与双键蓄爆，并重新设计管理员设置界面。Forge 和 Fabric 分别提供安装包，客户端和服务器必须安装同一版本。

## 玩家骑乘

- 空手或持非点燃物品右键未被骑乘的苦力怕上马，支持闪电苦力怕。手动点燃后拒绝骑乘；自然倒计时可抢先上马并取消。
- WASD 移动，空格跳跃，潜行下马。骑乘中关闭主动 AI 和自动爆炸；下马、死亡或坐骑被击杀时清理骑乘状态。
- 同时长按鼠标左右键蓄爆。准星下显示两位小数秒数，最后 1 秒为橙色；松开任意一键重置，下次从完整时长开始。
- 时长输入 0～120 秒，默认 2，支持小数；0 秒立即爆炸。玩家速度独立输入 1～10 倍，固定以默认普通骑士 0.375 移动属性为基准。
- 双键期间停止攻击、挖掘及使用物品，取消正在拉弓等动作；单键照常使用。骑乘时允许打火石/火焰弹点燃默认开启，可由管理员关闭；手动点燃的原版倒计时无法松键取消。
- 使用原版爆炸伤害、距离衰减、护甲与爆炸保护，不强制杀死玩家。方块破坏遵循 mobGriefing。
- 服务端计时和验证当前坐骑，客户端接收倒计时与速度同步。被玩家接管的空闲权杖坐骑清除原来的目标与存在时间。

## 设置界面

左侧七个分类，右侧完整选项可滚动，悬浮显示解释，所有数值直接输入。底部依次为恢复默认、取消、保存到服务器。

切换分类保留草稿和未输完的数值；取消、Esc 或退出丢弃草稿；恢复默认也只改变草稿。点击保存并收到服务端成功回复后才生效。设置仍仅限单人所有者或 OP 等级 2 及以上管理员修改，友尽权杖开启方块破坏仍需二次确认。

## 安装与验证

- Forge 47.4.10；Fabric Loader 0.16.14 + Fabric API 0.92.2+1.20.1；JDK 17。
- 两个平台各通过 293 项配置检查、7 个实际 Minecraft GameTest，以及客户端驾驶、计时同步、侧边栏草稿和保存检查。
- 真实鼠标硬件组合、两台独立客户端连接独立多人服务器、极高延迟及整合包兼容性仍需试玩。自动客户端测试通过开发输入夹具提供双键状态，网络、移动和渲染均实际运行。
- 升级时移除旧 jar，双方换为 3.0；旧世界配置保留，新增选项使用默认值。只安装适合加载器的一份 jar，Fabric 双方另需 Fabric API。
