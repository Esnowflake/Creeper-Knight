# 苦力怕骑士 0.2.1 · Minecraft Java 1.20.1

提供 Forge 与 Fabric 两个独立安装包，支持幼年僵尸家族苦力怕骑士、管理员图形设置和友尽权杖。

## 高速追击修复

- 修复高倍率时冲过路径点、反复掉头绕圈，难以命中目标的问题。
- 高速移动及时对准路径方向，直线路段提前跟随后续路径点，转角和接近目标时自动减速。
- 权杖高速追击每 2 刻更新路径，近距离逐刻跟踪目标位置。
- 关闭倒计时追击时，高速骑士制动停止；保留原版碰撞、寻路和爆炸流程。

## 主要玩法

- 支持幼年僵尸、尸壳、溺尸、僵尸村民和僵尸猪灵，自然生成、寻找苦力怕与指令召唤均可设置。
- 六组中英文图形设置、悬浮解释；多人服务器仅 OP 等级 2 及以上管理员可修改。
- 普通倒计时可继续追击，近距离瞬爆默认关闭、启用后默认距离 2 格。
- 友尽权杖按“苦力怕头颅 / 钻石 / 金锭”竖排合成，短按锁定玩家，长按 1 秒召唤。
- 锁定发光与聊天提示、五种召唤类型、0～120 秒存在时间及 1～10 倍专属速度可调整。
- 权杖骑士默认不破坏方块，开启需要二次确认，并受 `mobGriefing` 控制。

## 安装与升级

选择对应加载器的 **一个** jar，客户端和服务端都安装 0.2.1。升级时移除旧 jar 后重启，已有世界配置保留。

| 安装包 | 已验证环境 |
|---|---|
| `creeper-knight-0.2.1-mc1.20.1-forge.jar` | Forge 47.4.10，Java 17 |
| `creeper-knight-0.2.1-mc1.20.1-fabric.jar` | Fabric Loader 0.16.14 + Fabric API 0.92.2+1.20.1，Java 17 |

进入世界按 **K** 打开设置。默认权杖存在时间 30 秒、冷却 10 秒，生存模式每次成功召唤消耗一份火药。

## 验证

两平台构建通过，各通过 261 项配置检查和 6 个 Minecraft GameTest；高速追击覆盖八种场景，包括最大速度组合、移动玩家、0.5 格瞬爆和绕墙。客户端界面、内置服务器握手与设置同步检查通过。

独立多人服务器、其他模组整合包和长期区块加载场景仍需实测。详见 [README](https://github.com/Esnowflake/Creeper-Knight/blob/v0.2.1/README.md) 与 [验证记录](https://github.com/Esnowflake/Creeper-Knight/blob/v0.2.1/TESTING.md)。
